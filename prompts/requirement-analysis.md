# Prompt — Análise de requisitos

Use este prompt para pedir à IA uma segunda perspectiva sobre um requisito.

```text
Atue como um QA analisando requisitos.

Analise o requisito abaixo.

Identifique:
1. regras explicitamente definidas;
2. ambiguidades;
3. informações ausentes;
4. perguntas que deveriam ser feitas ao PO/negócio;
5. riscos ou cenários que dependem de esclarecimento.

Não invente respostas para as perguntas.
Diferencie claramente fatos presentes no requisito de hipóteses.

Requisito:
[INSIRA O REQUISITO]
```

## Objetivo

A IA deve ajudar a revelar lacunas, mas o requisito continua sendo a fonte de verdade para as regras do sistema.
