  ### Prompt enviado à LLM
    Explique o que é teste de software em no máximo 3 frases.

  ### Resposta da LLM
    O teste de software é o processo de verificar um programa ou sistema para identificar defeitos (bugs) e garantir que ele funcione conforme o esperado. O objetivo principal é assegurar a qualidade do software antes da entrega ao usuário final. Isso envolve executar o sistema com diferentes entradas para validar seu comportamento.
